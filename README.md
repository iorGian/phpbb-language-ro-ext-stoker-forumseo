# phpbb-language-ro-ext-stoker-forumseo

Romanian (`ro`) language pack for the phpBB extension **[stoker/forumseo](https://phpbb3bbcodes.com)** (Forum SEO).

Limba română (`ro`) pentru extensia phpBB **stoker/forumseo** (Forum SEO).

## Installation / Instalare

1. Copy the `ext/` folder into the root of your phpBB installation, merging it with the existing `ext/` directory. / Copiază folderul `ext/` în rădăcina instalării phpBB, îmbinându-l cu directorul `ext/` existent.
2. Purge the cache in the ACP (*General → Purge the cache*). / Golește cache-ul din ACP (*General → Golește cache-ul*).

Final path / Calea finală: `ext/stoker/forumseo/language/ro/`

## Files / Fișiere

- `common.php`
- `permissions_forumseo.php`
